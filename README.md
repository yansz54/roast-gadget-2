A single original line roasting the gadget/app I use every day — a password
manager that forgot the one password it was built to remember.

> My password manager forgot the one password it was built to remember: mine.

`main.ts` (Node 22, stdlib only, no network) writes that line to
`/output/entry.txt`. See [METHOD.md](METHOD.md) for how the line was chosen
from 24 candidates compared pairwise against the judge's criteria.
